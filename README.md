# Hybrid Machine Learning Pipeline for Movie Segmentation and Revenue Prediction
Developed an end-to-end machine learning pipeline to cluster movies based on budget, runtime, and vote average using
K-Means and Hierarchical clustering, determining the optimal number of clusters via inertia and silhouette analysis. Built
and trained a fully connected neural network with ReLU activations to predict movie revenue, implementing proper data
preprocessing, normalization, and train/validation/test splits. Evaluated model performance using Mean Squared Error
(MSE) and R2, demonstrating practical skills in exploratory data analysis, unsupervised learning, and regression with
deep learning.
